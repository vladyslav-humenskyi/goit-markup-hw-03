# goit-markup-hw-03

GoIT Fullstack HTML/CSS homework #3: **Flexbox layout**.

The project is the landing page of **WebStudio**, a fictional web studio ("Effective Solutions for Your Business"), built from the course mockup. Each homework in the `goit-markup-hw-0X` series builds on the previous one.

**Live page:** [https://vladyslav-humenskyi.github.io/goit-markup-hw-03/](https://vladyslav-humenskyi.github.io/goit-markup-hw-03/)

## What's done

- Page layout built with Flexbox: header and navigation, hero, features grid, team cards, portfolio grid and footer
- Shared `.section` and container styles in `common.css`
- Typography and colors carried over from homework #2

## Structure

```
index.html
css/
  main.css        imports all the files below
  common.css      shared styles
  header.css  hero.css  features.css  team.css  portfolio.css  footer.css
images/
```

## Run locally

No build step. Open `index.html` in a browser or serve the folder with a static server such as VS Code Live Server.
